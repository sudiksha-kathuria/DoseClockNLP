## Evidence, temporary files and secrets

- **Preserved:** all 231 pre-existing evidence files were checked against the
  pre-change SHA-256 manifest and remain unchanged. Before-report/source snapshots
  preserve the October 23 state. Historical passes, failures, raw measurements and
  autoplay diagnostics were not deleted or silently rewritten.
- **No database/key/runtime cache detected in the checkout:** no `.db`, SQLite,
  `.secret_key`, `.env`, private-key file or Python bytecode cache was found in
  the final audit. Real application tests use temporary exports and disposable
  databases. Generated speech files are evidence under `docs/testing/evidence`,
  not the application's ignored runtime cache.
- **Credentials:** assignment/key/pattern review found placeholders, explicit dummy
  account passwords, invalid-token fixtures and redacted token fields. No live
  Wi-Fi password, pairing token, cookie, API key or private key was detected in
  files proposed for commit. This is a scoped scan/manual review, not a proof that
  every conceivable secret is absent. Do not replace firmware placeholders with
  live values in the tracked sketch.
- **Oversized file:**
  `docs/testing/evidence/followup_20261023/regression_browser_wire/requests.json`
  is **18,467,421 bytes** (about 17.61 MiB), the only file over the audit's 5 MiB
  threshold. Keep the complete original locally; commit the compact wire audit,
  hash and representative relevant calls instead. Do not delete the trace.
- **Full raw traces/snapshots:** `requests.json`, `cdp.jsonl`, duplicated source
  snapshots and historical build-helper copies are useful archives but usually
  poor source-commit payloads. Preserve them locally. The individual audit entry
  distinguishes these from small result JSON, CSV, terminal logs and screenshots.
- **Generated MP3s/screenshots:** retain genuine originals. Small redacted/dummy
  screenshots can accompany evidence. Keep generated MP3s local by default, or
  explicitly include them as reviewed evidence attachments; valid metadata/hashes
  and regeneration commands are already recorded. Do not stage all media by glob.
- **Outside the repository:** virtual environments, browser profiles, private full
  Playwright wire logs, exported databases/keys and Arduino downloads/build caches
  under `/private/tmp` remain local. Temporary browser/DB exports are cleaned by
  the harness. Full private wire logs may contain dummy authentication data and
  must not be copied wholesale into a commit.
- **Do not delete:** original logs/results/media, even if omitted from a commit.
  The local archive is the complete record; the proposed commit is a curated,
  reviewed subset. Publishing a complete archive can be a separate approved step.
